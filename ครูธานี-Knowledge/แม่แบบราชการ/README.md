## ๑. บันทึกข้อความ (หนังสือภายใน)

**หน้ากระดาษ** A4 แนวตั้ง

| ขอบ | ค่า |
|-----|-----|
| ซ้าย | **๓ ซม.** (1728 twips ≈ 3.05) |
| ขวา | **๒ ซม.** (1152 twips ≈ 2.03) |
| บน | 1.75 ซม. |
| ล่าง | 0.76 ซม. |
| หัว/ท้ายกระดาษ | 1.25 ซม. |

**ครุฑ** ขนาดเล็ก สูง **1.5 ซม.** (กว้าง 1.38) ชิดขอบซ้าย บรรทัดเดียวกับคำว่า "บันทึกข้อความ"

**หัวกระดาษ**
- "บันทึกข้อความ" — TH SarabunIT๙ **29 pt ตัวหนา** กึ่งกลาง
- กล่องรับหนังสือมุมขวาบน (กว้าง 5.74 × สูง 2.68 ซม.) "วิทยาลัยการอาชีพบุรีรัมย์ / งานบริหารงานทั่วไป / รับเลขที่…ส่งให้… / วันที่…เวลา…น." 14 pt
- ส่วนราชการ / ที่ / วันที่ / เรื่อง — **20 pt ตัวหนา** (เฉพาะคำนำหน้า) + เส้นจุดไข่ปลา
- "วันที่" อยู่ที่ tab 7.76 ซม. (4395 twips)
- ใต้ "เรื่อง" มีเส้นตรงยาวเต็มบรรทัด (15.7 ซม.)

**เนื้อความ** TH SarabunIT๙ **16 pt**
- เรียน — tab 2.25 ซม. (1276 twips), เว้นหลัง 6 pt
- ย่อหน้า — เยื้องบรรทัดแรก **3 ตัวอักษร (≈1.67 ซม.)**, เยื้องขวา 0.26 ซม., จัดแบบ **กระจายแบบไทย (Thai Distributed)**, เว้นหลัง 6 pt
- "จึงเรียนมาเพื่อโปรดพิจารณา" — เยื้องซ้าย 1.27 ซม. + บรรทัดแรก 0.42
- ลงชื่อ / (ชื่อ) / ตำแหน่ง — กึ่งกลางค่อนขวา
- ช่องความเห็น **รองผู้อำนวยการ (ซ้าย) | ผู้อำนวยการ (ขวา)** — หัวข้อ 16 pt ตัวหนา

**เอกสารแนบ** (ขึ้นหน้าใหม่ด้วย Page Break Before)
- หัวเรื่อง 18 pt ตัวหนา กึ่งกลาง / หัวเรื่องรอง 16 pt ตัวหนา
- ตาราง 15 pt, จัดตารางกึ่งกลาง, หัวตารางตัวหนา, ตัวเลขเงินชิดขวา, แถว "รวมทั้งสิ้น" ตัวหนา
- ปิดท้ายด้วย "หมายเหตุ" 15 pt ทุกตาราง

## ๒. หนังสือภายนอก

**หน้ากระดาษ** A4 แนวตั้ง

| ขอบ | ค่า |
|-----|-----|
| ซ้าย | **๓ ซม.** (1701 twips) |
| ขวา | **๒ ซม.** (1134 twips) |
| บน | ๒ ซม. |
| ล่าง | 0.75 ซม. |

**ครุฑ** ขนาดใหญ่ (กว้าง 3.45 × สูง 3.5 ซม. รวมขอบภาพ) **กึ่งกลางหน้ากระดาษ**
(ห่างขอบข้อความซ้าย 6.21 ซม. ในพื้นที่กว้าง 16 ซม.)

**ส่วนหัว** ทั้งฉบับ TH SarabunIT๙ **16 pt** ไม่ตัวหนา
- ซ้าย: `ที่  ศธ ๐๖๓๕.๐๔/` (เว้นเลขให้งานสารบรรณกรอก)
- ขวา: กล่องที่อยู่ (กล่องข้อความไม่มีกรอบ เริ่มที่ 9.56 ซม.) "วิทยาลัยการอาชีพบุรีรัมย์ / ๑๓๘ ถนนจิระ ตำบลในเมือง / อำเภอเมืองบุรีรัมย์ จังหวัดบุรีรัมย์ ๓๑๐๐๐"
- วัน เดือน ปี — เยื้องซ้าย 7.62 ซม. (3600+720 twips), เว้นก่อน 12 pt
- เรื่อง / เรียน — Hanging 1.27 ซม., เว้นก่อน 6 pt

**เนื้อความ** — tab ย่อหน้า **2.5 ซม. (1418 twips)**, กระจายแบบไทย, เว้นก่อนย่อหน้า 6 pt

**รายชื่อผู้ไปราชการ** (จุดที่ ผอ. ดูละเอียด) — **เคาะเข้ามาข้างใน**
- เยื้องซ้าย **2.5 ซม.** แล้วกด Tab ไปที่ **3.5 ซม. (1985 twips)** ก่อนเลขลำดับ
- รูปแบบ: `๑. นายวิรัช สุวรรณทา  [Tab]  ตำแหน่งรองผู้อำนวยการฝ่ายวิชาการ`
- ชื่อ–ตำแหน่งต้องอยู่บรรทัดเดียวกัน คำว่า "ตำแหน่ง" ต้องตรงกันทุกบรรทัด

**ส่วนท้าย**
- "ขอแสดงความนับถือ" — กด Tab ๖ ครั้ง + เว้น ๒ เคาะ
- เว้น ๓ บรรทัดสำหรับลายเซ็น
- (นางสาวรัชญา คนธขจร) — เยื้องซ้าย 6.35 ซม. (3600 twips)
- ผู้อำนวยการวิทยาลัยการอาชีพบุรีรัมย์
- ซ้ายล่าง: ฝ่ายวิชาการ / แผนกวิชาช่างเชื่อมโลหะ / โทรศัพท์ ๐ ๔๔๖๑ ๒๒๖๐ / โทรสาร ๐ ๔๔๖๑ ๓๓๕๔

## หมายเหตุการเก็บไฟล์

- ไฟล์ `หนังสือภายนอก-…docx` ที่เก็บไว้ แก้เลขอารบิกที่หลุดมา ๔ จุดเป็นเลขไทยแล้ว (`3`→`๓` พ.ย., `๑0`→`๑๐`, `๑5`→`๑๕`, `2.`→`๒.`) นอกนั้นเหมือนต้นฉบับทุกอย่าง
